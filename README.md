## 📌 Overview

SmartPower is a full-stack energy management system for monitoring and optimizing power usage in real time.

Built with:

- **Frontend:** React + TypeScript + Vite
- **Backend:** Flask + SQLAlchemy + SQLite

The platform helps homes, campuses, and facilities make smarter energy decisions using AI-powered forecasting, anomaly detection, and live analytics.

---

# ✨ Features

- ⚡ Real-Time Energy Monitoring
- ☀️ Solar Generation Tracking
- 📊 Live Net Load Analytics
- 💰 Energy Cost Estimation
- 🌱 CO₂ Savings Tracking

- 🚨 Z-Score Anomaly Detection
- 🔔 Smart Alerts System
